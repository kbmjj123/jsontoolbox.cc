# 隐私政策

**最后更新时间：** 2026 年 11 月 12 日

本隐私政策说明 JsonToolBox（"我们"、"我们的"）在你使用我们的网站及工具（[jsontoolbox.cc](https://jsontoolbox.cc)）以及 JSON Toolbox 浏览器扩展（Chrome / Edge）时，如何收集、使用和保护你的信息。

**适用范围。** 第 1–8 节说明 jsontoolbox.cc 网站；第 9 节说明浏览器扩展。扩展是独立安装在浏览器本地的产品：网站可能使用广告和统计分析，但扩展不含广告、分析和遥测。第 10–12 节同时适用于两者。

本政策中凡提及「我们不收集」，均指我们不会在服务器上接收你的数据；两个产品都在你的设备本地处理 JSON。

使用 JsonToolBox 即表示你同意本隐私政策的条款。

## 1. 数据处理 — 100% 客户端

JsonToolBox 中的所有 JSON 和文件处理**完全在浏览器中**通过 JavaScript 完成。你的数据：

- **不会被上传** 到任何服务器
- **不会远程存储**
- **不会为了处理而被传输** 到网络

我们无法访问你在使用工具时处理的 JSON、文件或任何其他内容。关闭页面后，网站不会保留这些数据的任何副本。（浏览器扩展会有意在你的设备上保留最近一次预览，见第 9.3 节。）

### 如何自行验证

我们鼓励技术用户验证我们的隐私声明：

1. **打开开发者工具** → 进入 **Network** 标签
2. **粘贴你的 JSON** 到任意工具，点击格式化 / 转换 / 验证
3. **检查 Network 标签** — 你不会看到任何与 JSON 内容相关的请求

本站发出的网络请求仅用于加载页面本身（HTML、CSS、JS）和 Google AdSense 广告。你的 JSON 内容不会出现在任何请求中。

你也可以查看我们的 [GitHub 源代码](https://github.com/kbmjj123/jsontoolbox.cc) 来验证没有数据被发送到外部服务器。

## 2. 我们不收集的信息

我们明确**不会收集**：

- 你粘贴到工具中的 JSON、文件或任何数据的内容
- 通过工具使用产生的个人信息（例如你 JSON 中的姓名、邮箱、ID 等）
- 任何可用于还原你输入内容的数据

## 3. 广告 — Google AdSense

我们使用 **Google AdSense** 在网站上展示广告。Google AdSense 可能使用 Cookie 或类似技术，基于你对本站和其他网站的访问来投放广告。

- Google 使用广告 Cookie 使其及其合作伙伴可以根据你对本站和/或互联网上其他网站的访问来投放广告。
- 你可以通过访问 [Google 广告设置](https://adssettings.google.com/) 来选择退出个性化广告。

**重要说明：** Google AdSense 独立于我们的 JSON 工具运行。你的 JSON 数据绝不会与 Google 或任何广告商共享。广告作为独立的页面资源加载，无法访问你在工具中处理的内容。

## 4. 统计分析

我们可能使用注重隐私的网页分析工具来了解网站的使用情况。可能包括：

- 页面浏览和导航路径
- 来源信息（例如搜索引擎、社交媒体）
- 设备类型、浏览器类型以及大致位置（例如国家/地区）

这些数据是匿名和聚合的，**不包含**你的 JSON 内容，也不包含任何可以识别你个人身份的信息。

## 5. Cookie

我们仅出于必要功能使用最少的 Cookie，例如：

- 记住你的主题偏好（浅色/深色模式）
- 记住你的语言设置

我们**不会**将 Cookie 用于：

- 跨站追踪
- 向第三方出售数据

你可以通过浏览器设置控制或禁用 Cookie。禁用 Cookie 可能会影响部分网站功能（例如主题记忆的持久化）。

## 6. 第三方服务

| 服务 | 用途 | 共享的数据 |
|------|------|-----------|
| Google AdSense | 广告展示 | 页面URL、浏览器信息（不含JSON内容） |

我们**不会**将你的 JSON 数据与任何第三方服务共享。

浏览器扩展在预览媒体 URL 时产生的第三方请求属于另一种情况，见第 9.4 节：这些请求发往你 JSON 中 URL 的托管服务器，而不是发往我们与之共享数据的服务商。

## 7. 开源透明

JsonToolBox 是一个**开源项目**。你可以检查每一行代码来验证我们的隐私声明：

- [GitHub 仓库](https://github.com/kbmjj123/jsontoolbox.cc)
- 不存在服务端 JSON 处理代码 — 因为根本没有服务端处理
- 所有 JSON 操作使用浏览器原生的 `JSON.parse` / `JSON.stringify` 和客户端库

## 8. 你的选择

你可以：

- 通过浏览器设置在不启用 Cookie 的情况下使用 JsonToolBox
- 随时清除浏览器数据
- 随时停止使用本网站；我们不会保留任何数据
- 使用浏览器扩展或 [Google 广告设置](https://adssettings.google.com/) 屏蔽 Google AdSense 广告

## 9. 浏览器扩展（Chrome / Edge）

[JSON Toolbox 浏览器扩展](https://github.com/kbmjj123/json-browser-plugins)是与本站一同维护的独立开源项目，完全运行在你的浏览器内。上文第 3–5 节（网站的广告、统计分析与 Cookie）不适用于它，以下条款专门说明扩展的行为。

### 9.1 扩展的功能

对于浏览器原本会以纯文本展示的 JSON 文档，扩展会自动渲染为可查看、可编辑的界面。解析、格式化、搜索与编辑全部在浏览器本地完成。

### 9.2 扩展不收集的数据

我们不会在服务器上收集、接收或存储你的任何数据。扩展没有账号、无需登录，也不含遥测、统计分析、崩溃上报、广告或任何第三方 SDK。我们不会出售或共享个人信息，你的数据也不会被用于广告投放或模型训练。

### 9.3 保存在你设备上的数据

扩展通过 `browser.storage.local` 保存：

- 你的偏好设置（主题、缩进、默认视图、语言、自动美化、媒体预览）；
- 最近一次预览的 JSON 文档正文、该页面的 URL 以及时间戳，以便点击工具栏按钮时在独立标签页中重新打开。

这些数据不会离开你的设备，也不会同步到其他设备；下一次预览会覆盖上一次的内容。卸载扩展，或在 Chrome 中清除该扩展的存储数据，即可将其删除。jsontoolbox.cc 网站无法读取这部分存储。

### 9.4 发往第三方服务器的请求

在 ⚙ 设置中开启「图片预览」（默认开启）后，JSON 中作为值出现的 URL 可能会被浏览器以图片、音频、视频或 PDF 框架的形式加载。请求发往托管这些 URL 的服务器，而不是发给我们，并可能携带浏览器对该站点通常会附带的 referrer 信息。如果 URL 中含有令牌或查询参数，托管方也能看到它们。内联的 `data:` / base64 图片直接渲染，不产生任何请求。

「下载全部」是你在图片放大视图中手动触发的独立操作，会直接请求所选 URL，因此仍会联系这些 URL 的托管服务器。

关闭「图片预览」即可禁用这类自动发起的媒体请求。

### 9.5 链接

查看器内含指向 https://jsontoolbox.cc 的链接，以及一个可选的赞助链接 https://ko-fi.com/kbmjj123。只有你点击时，它们才会在新标签页打开，并受这些站点各自隐私政策的约束。在中文界面下，赞助链接改为显示随扩展打包的本地二维码图片，不会发起网络请求。

### 9.6 权限

`storage`（保存本地偏好和最近一次预览），以及注册到所有站点和 `file://` URL 的 content script（用于识别 JSON 页面；访问本地文件还需你在 Chrome 中开启「允许访问文件网址」）。扩展未申请 `host_permissions`、`tabs`、`clipboardWrite` 或 `unlimitedStorage` 权限。

### 9.7 源码

扩展源码公开在 [GitHub](https://github.com/kbmjj123/json-browser-plugins)。你可以像第 1 节对网站所做的那样，检查源码以核实上述说明。
