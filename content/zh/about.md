# 关于 JSON Toolbox

JSON Toolbox 是一个免费、开源的开发者 JSON 工具集合。
所有处理直接在浏览器中完成 — 你的数据永远不会离开你的设备。

## 我们的使命

我们认为开发者应该能够使用高质量的 JSON 工具，同时不必牺牲隐私。JSON Toolbox 中的每个工具都完全在浏览器中运行，使用纯前端 JavaScript — 数据不会上传到任何服务器。

## 为什么选择 JSON Toolbox？

- **100% 客户端处理：** 所有处理在浏览器中完成，JSON 数据永远不会离开你的设备。
- **永久免费：** 无需注册，没有限制，没有隐藏费用。
- **隐私优先：** 不追踪用户，不存储数据，不展示侵入性广告。
- **开源透明：** 代码公开，接受社区审查和贡献。

## 可用工具

JSON Toolbox 包括格式化、验证、转换、比较和浏览 JSON 数据的工具。无论你是调试 API 响应的开发者、将 JSON 转换为 CSV 的数据分析师，还是学习 JSON 的学生 — 我们都能帮到你。
