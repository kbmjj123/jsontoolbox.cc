# Über JSON Toolbox

JSON Toolbox ist eine kostenlose, Open-Source-Sammlung von JSON-Tools für Entwickler.
Die gesamte Verarbeitung findet direkt in deinem Browser statt — deine Daten verlassen nie dein Gerät.

## Unsere Mission

Wir glauben, dass Entwickler Zugang zu hochwertigen JSON-Tools haben sollten, ohne ihre Privatsphäre zu gefährden. Jedes Tool in JSON Toolbox läuft vollständig in deinem Browser mit clientseitigem JavaScript — es werden niemals Daten auf einen Server hochgeladen.

## Warum JSON Toolbox?

- **100 % clientseitig:** Die gesamte Verarbeitung findet in deinem Browser statt. Deine JSON-Daten verlassen nie dein Gerät.
- **Für immer kostenlos:** Keine Anmeldung, keine Limits, keine versteckten Gebühren.
- **Datenschutz zuerst:** Wir verfolgen dich nicht, speichern deine Daten nicht und zeigen keine aufdringlichen Werbeanzeigen.
- **Open Source:** Unser Code ist öffentlich zugänglich für Transparenz und Beiträge der Community. Alle vier Repositories findest du auf der [Entwicklerseite](/developers).

## Verfügbare Tools

JSON Toolbox enthält Tools zum Formatieren, Validieren, Umwandeln, Vergleichen und Erkunden von JSON-Daten. Ob du Entwickler bist, der eine API-Antwort debugt, Datenanalyst, der JSON in CSV umwandelt, oder Student, der JSON lernt — wir haben dich abgedeckt.
