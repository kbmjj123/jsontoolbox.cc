# 需求 06：跨框架 Web Component（条件启动）

## 状态与启动门槛

优先级：P2，暂不默认开发。至少收集明确的非 Vue 接入需求，确认 iframe 不能满足样式、事件或宿主数据交互要求后，再由维护者批准启动。先做技术验证，不直接承诺发布。

## 目标与非目标

让普通 HTML 或非 Vue 应用能够加载同一编辑器核心。不是为增加 npm 条目，不重写 React/Angular 版本，不替代已经可用的 iframe。

## 调查与方案比较

比较现有组件封装为 Custom Element、轻量 mount API 和继续使用 iframe 三种方案，记录运行时依赖、包体、CSS 隔离、资源路径、SSR 和安全边界。不能假设现有 Vue 组件可零修改运行在 Shadow DOM 内。

## API 需求

拟定带命名空间的元素名，最终需确认。字符串属性用于简单配置；大 JSON 通过 property/API 传递，不塞入 HTML 属性。定义受控/非受控模式、输入输出格式、ready/change/error 事件，以及程序性更新是否触发 change，避免循环。

明确自定义元素重复注册、初始化失败、销毁、重新连接和多实例行为。移除元素后释放 Worker、监听器和相关资源。

## 样式与资源

验证编辑器浮层、菜单、主题、字体、Worker 和图标在 Shadow DOM 或其他隔离策略下工作。支持固定版本资源，自托管部署不强制访问官网 CDN。不承诺未经测试的 CSP 兼容。

## 安全与交互

不使用任意 HTML 注入展示 JSON，不请求远程数据。复制、键盘、焦点、移动端及大输入限制与现有组件保持一致。官网入口不携带数据，品牌关闭不影响功能。

## 交付

普通 HTML 可运行示例、一个非 Vue 框架接入示例、API 文档、构建产物、包体与兼容性记录。包名和分发渠道待确认；仅在验证独立使用价值后发布。

## 验收与停止条件

页面无 Vue 应用上下文也可使用；多实例和重复挂载稳定；事件不回环；销毁无明显资源泄漏；固定版本及自托管资源可运行。若包体或样式隔离成本明显超出收益，回退到 mount API 或 iframe，并记录不继续封装的结论。

## 通用实施约束

1. 本文为需求与验收依据，不代表仓库已经具备文中能力。实施前检查实际代码、构建脚本、许可证、组件 API 和发布配置；不得虚构检查结果。
2. 产品名称统一为 JsonToolBox；官网为 https://jsontoolbox.cc/；主仓库为 https://github.com/kbmjj123/jsontoolbox.cc。新增包名、镜像名和仓库名均为待确认建议，发布前检查可用性。
3. 优先复用现有编辑器与处理逻辑，不复制维护第二套核心，不引入与需求无关的账号、数据库、云端处理和许可证验证服务。
4. JSON 内容不得默认上传、写入分析事件或附加在外部链接中；错误日志不得包含用户原文。不要把“本地处理”直接等同于整个页面没有外部请求。
5. 官网、源码和许可链接用于说明来源。不得要求强制反链、指定 dofollow、隐藏链接或堆砌关键词；品牌展示可关闭，不得影响功能。许可证义务以仓库实际许可证为准，不将保留网页反链描述为 MIT 的要求。
6. 新增追踪、外部服务、软件包发布、平台提交和对第三方发起 PR 均需维护者确认。默认不增加遥测。
7. 不为链接数量创建空壳包、重复仓库或无实际用途的适配层。下载、拉取、引用和真实用户分别统计，不混为一谈。
8. 使用项目现有包管理器、测试方案和编码规范；本文示例命名可按仓库结构调整，调整需说明理由。

## 开工前必须输出

- 相关文件、组件入口、构建命令及当前行为的检查记录。
- 已有能力、缺失能力和阻塞项列表；不能确认的内容标记“待核实”。
- 最小变更方案、拟修改文件清单及复用关系。
- 本次验收方式与回归范围。遇到架构或发布权限阻塞时停止猜测，记录需要维护者确认的决策。

- 可运行代码或配置、中文及英文使用说明、实际执行的测试结果、已知限制、回滚方式。
- 文档内命令必须在目标环境验证；未执行的测试标为“未验证”，不能直接勾选通过。
- 不影响官网现有工具、现有组件消费者及 Obsidian 插件；相关共享核心发生变更时执行回归。
- 发布前提供变更摘要、涉及外部服务清单和维护成本说明。未获得发布授权时仅交付待发布产物与操作说明。
