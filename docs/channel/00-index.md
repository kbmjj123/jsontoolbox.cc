# JsonToolBox 分发与集成需求文档索引

## 使用方式

每份文档可独立交给开发代理执行。先阅读“开工前必须输出”，检查现有代码，再列任务和实施。每份通用约束均已完整附入，脱离索引也可使用。本文档不代表已经检查当前源码或平台最新规则。

| 文档 | 优先级 | 前置条件 |

| 01 Docker 自托管 | P0 | 审计项目构建与外部依赖 |
| 02 VitePress 集成 | P1 | 现有 Vue 组件可复用 |

## 推荐顺序

01 → 02 → 03；01 完成后可独立安排 04；02 完成后可开始 05。06、07 不是默认排期承诺，满足门槛才启动。独立维护者不宜同时开启全部方向。

## 统一评估原则

先验证真实复用与使用价值，再扩大平台覆盖。官网链接承担来源与在线演示功能，不强制反链，不承诺排名收益。自建实例、镜像拉取、包下载、公开案例和第三方自主推荐分别记录。
