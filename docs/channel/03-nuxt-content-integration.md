# 需求 03：Nuxt Content 交互式 JSON 内容示例

## 优先级与目标

优先级：P1，排在 VitePress 示例之后。为 Nuxt Content 内容作者提供可复用的 JSON 展示/编辑区块。先交付示例与薄适配层，不默认创建通用 Nuxt Module。

## 前置调查

检查目标仓库使用的 Nuxt、Nuxt Content 版本、内容目录、MDC 配置、组件发现规则、编辑器 SSR 限制和静态生成方式。不能套用不匹配版本的目录约定。

建议示例放在 examples/nuxt-content；若现有仓库已经有合适内容演示则复用。保留现有主站内容生产流程。

## 功能需求

### 内容组件

提供一个命名明确、带命名空间的内容组件，例如 JsonToolBoxViewer，实际名称待确认。默认只读，提供主题、高度、展开行为和编辑开关。优先复用既有 Vue 组件。

需要明确 JSON 传入方式：本地示例文件、受控 prop 或经过确认的代码块内容。验证引号、换行、Unicode、反斜杠与嵌套对象能往返保留；不使用执行字符串的方式解析数据。

### 示例覆盖

1. API 响应说明文章：正文与树形视图搭配。
2. 教程文章：主动启用编辑和重置示例。
3. 无效 JSON 与大输入：可理解的提示，不破坏整篇文章。
4. 两个独立组件实例：互不影响。

### 渲染与资源

SSR、静态生成和客户端导航均能使用。客户端专用依赖延迟导入；有合适的静态降级内容。检查不同部署基址的 Worker、CSS 和图标路径，避免写死官网。

交互性不应强迫整篇文章变成纯客户端渲染，不修改全局 SSR 设置解决局部组件问题。避免对没有使用编辑器的页面加载全部编辑器资源，记录实际构建变化。

### 内容边界与来源链接

公开文章中的示例就是公开内容，编辑器本地处理不意味着原始文章数据保密。所有演示只使用模拟数据。

文档提供官网演示、组件和源码入口；不自动给每篇文章插入 SEO 链接。若提供“完整工具”按钮，默认不发送当前 JSON，按钮行为在文档中说明。

## 实施任务

- [ ] 确认内容版本和组件映射机制。
- [ ] 定义输入格式、API 与编辑状态生命周期。
- [ ] 编写薄适配组件和真实文章示例。
- [ ] 验证 SSR、静态输出、客户端切换和主题。
- [ ] 测试特殊字符、多实例、错误和资源加载。
- [ ] 写中英文复制接入步骤和故障排查。

## 验收

新项目可按说明复现；Markdown/MDC 内容能够稳定解析；JSON 文本不被当成 HTML 执行；编辑、重置不修改源文章；未使用页面不无故加载整套编辑器；移动端与深色主题可用；现有官网内容路由和 SEO 配置不受影响。

## 何时再做 Nuxt Module

只有多个真实使用者重复需要自动注册组件、统一样式配置或 SSR 边界处理时，另行评估模块。先列出模块能省掉的具体步骤，再决定是否增加发布与版本兼容责任。

## 通用实施约束

1. 本文为需求与验收依据，不代表仓库已经具备文中能力。实施前检查实际代码、构建脚本、许可证、组件 API 和发布配置；不得虚构检查结果。
2. 产品名称统一为 JsonToolBox；官网为 https://jsontoolbox.cc/；主仓库为 https://github.com/kbmjj123/jsontoolbox.cc。新增包名、镜像名和仓库名均为待确认建议，发布前检查可用性。
3. 优先复用现有编辑器与处理逻辑，不复制维护第二套核心，不引入与需求无关的账号、数据库、云端处理和许可证验证服务。
4. JSON 内容不得默认上传、写入分析事件或附加在外部链接中；错误日志不得包含用户原文。不要把“本地处理”直接等同于整个页面没有外部请求。
5. 官网、源码和许可链接用于说明来源。不得要求强制反链、指定 dofollow、隐藏链接或堆砌关键词；品牌展示可关闭，不得影响功能。许可证义务以仓库实际许可证为准，不将保留网页反链描述为 MIT 的要求。
6. 新增追踪、外部服务、软件包发布、平台提交和对第三方发起 PR 均需维护者确认。默认不增加遥测。
7. 不为链接数量创建空壳包、重复仓库或无实际用途的适配层。下载、拉取、引用和真实用户分别统计，不混为一谈。
8. 使用项目现有包管理器、测试方案和编码规范；本文示例命名可按仓库结构调整，调整需说明理由。

## 开工前必须输出

- 相关文件、组件入口、构建命令及当前行为的检查记录。
- 已有能力、缺失能力和阻塞项列表；不能确认的内容标记“待核实”。
- 最小变更方案、拟修改文件清单及复用关系。
- 本次验收方式与回归范围。遇到架构或发布权限阻塞时停止猜测，记录需要维护者确认的决策。

## 交付与完成定义

- 可运行代码或配置、中文及英文使用说明、实际执行的测试结果、已知限制、回滚方式。
- 文档内命令必须在目标环境验证；未执行的测试标为“未验证”，不能直接勾选通过。
- 不影响官网现有工具、现有组件消费者及 Obsidian 插件；相关共享核心发生变更时执行回归。
- 发布前提供变更摘要、涉及外部服务清单和维护成本说明。未获得发布授权时仅交付待发布产物与操作说明。
