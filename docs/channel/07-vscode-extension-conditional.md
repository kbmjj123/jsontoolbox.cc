# 需求 07：VS Code 本地 JSON 工作区扩展（条件启动）

## 状态与启动门槛

优先级：P2。只有已有用户明确需要在编辑器内使用树形查看、结构对比或其他差异化能力时启动。先确定一个主场景，不将主站全部工具搬进扩展。不做只打开官网的空壳扩展。

## 最小范围

建议首场景：通过命令将当前选中的 JSON 或当前 JSON 文档打开为本地树形查看工作区。选区与整文件的优先级需明确；无选区、空文件、无效输入给出清晰提示。

首版默认只读；搜索、复制、展开和重新加载按已有组件能力交付。结构 Diff、字符串解码等作为后续候选，不同时强行纳入首版。

## 架构与安全

复用已有组件，扩展侧只承担编辑器命令、数据传递和 Webview 生命周期。所有 UI、Worker 和必要资源随扩展打包，不加载官网脚本。

Webview 按最小能力配置 CSP、资源访问范围及消息协议；不使用任意脚本执行传递数据。对消息类型、数据大小及来源边界进行验证，不把 Webview 消息当可信指令。

不读取整个工作区、不扫描其他文件、不默认写磁盘、不上传 JSON。日志避免原文。明确 Workspace Trust 策略，按支持范围测试；不声称兼容所有远程或 Web 编辑器环境。

## 状态与生命周期

文档关闭、外部修改、切换选区、面板隐藏和销毁行为应明确。首版可采用手动重新载入，避免复杂实时同步。若未来允许编辑回写，必须独立设计确认、撤销和冲突处理，本次不隐式覆盖原文件。

大输入复用已有安全阈值，不因扩展入口绕过限制。错误展示不泄漏本地文件绝对路径到第三方。

## 命令与来源说明

命令使用清晰品牌前缀，例如 JsonToolBox: Open JSON Viewer，最终名称按体验确认。关于页可提供官网、源码和许可链接；用户主动打开官网时不携带文档内容。

## 发布要求

先生成 VSIX 并手工验证，再评估官方 Marketplace 和 Open VSX 的当前发布、许可和账号要求。两处发布并不等于全部兼容编辑器都受支持。密钥仅进入受控 CI Secret，不写仓库或日志。平台发布由维护者批准。

## 实施任务

- [ ] 记录真实需求并确认唯一首场景。
- [ ] 技术验证现有组件在 Webview 内的加载与主题。
- [ ] 实现命令、输入选择、只读工作区和生命周期。
- [ ] 完成 CSP、消息校验及本地资源策略。
- [ ] 测试多面板、无效 JSON、大输入和断网使用。
- [ ] 提供截图、中英文说明、隐私政策和限制。

## 验收

不访问官网也能完成主场景；无 JSON 上传；不会修改源文件；无多余文件读取；Webview 销毁后释放资源；主题与键盘交互正常；错误与大输入不会拖垮宿主；打包产物在明确支持的环境可安装使用。

## 继续投入条件

根据真实活跃反馈、具体使用问题和维护成本决定增加功能。不仅凭商店安装数或页面链接判断成功；无人使用时不继续扩展功能矩阵。

## 通用实施约束

1. 本文为需求与验收依据，不代表仓库已经具备文中能力。实施前检查实际代码、构建脚本、许可证、组件 API 和发布配置；不得虚构检查结果。
2. 产品名称统一为 JsonToolBox；官网为 https://jsontoolbox.cc/；主仓库为 https://github.com/kbmjj123/jsontoolbox.cc。新增包名、镜像名和仓库名均为待确认建议，发布前检查可用性。
3. 优先复用现有编辑器与处理逻辑，不复制维护第二套核心，不引入与需求无关的账号、数据库、云端处理和许可证验证服务。
4. JSON 内容不得默认上传、写入分析事件或附加在外部链接中；错误日志不得包含用户原文。不要把“本地处理”直接等同于整个页面没有外部请求。
5. 官网、源码和许可链接用于说明来源。不得要求强制反链、指定 dofollow、隐藏链接或堆砌关键词；品牌展示可关闭，不得影响功能。许可证义务以仓库实际许可证为准，不将保留网页反链描述为 MIT 的要求。
6. 新增追踪、外部服务、软件包发布、平台提交和对第三方发起 PR 均需维护者确认。默认不增加遥测。
7. 不为链接数量创建空壳包、重复仓库或无实际用途的适配层。下载、拉取、引用和真实用户分别统计，不混为一谈。
8. 使用项目现有包管理器、测试方案和编码规范；本文示例命名可按仓库结构调整，调整需说明理由。

## 开工前必须输出

- 相关文件、组件入口、构建命令及当前行为的检查记录。
- 已有能力、缺失能力和阻塞项列表；不能确认的内容标记“待核实”。
- 最小变更方案、拟修改文件清单及复用关系。
- 本次验收方式与回归范围。遇到架构或发布权限阻塞时停止猜测，记录需要维护者确认的决策。

## 交付与完成定义

- 可运行代码或配置、中文及英文使用说明、实际执行的测试结果、已知限制、回滚方式。
- 文档内命令必须在目标环境验证；未执行的测试标为“未验证”，不能直接勾选通过。
- 不影响官网现有工具、现有组件消费者及 Obsidian 插件；相关共享核心发生变更时执行回归。
- 发布前提供变更摘要、涉及外部服务清单和维护成本说明。未获得发布授权时仅交付待发布产物与操作说明。
