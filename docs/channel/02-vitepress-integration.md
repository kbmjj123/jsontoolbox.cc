# 需求 02：VitePress 交互式 JSON 文档示例

## 优先级与目标

优先级：P1。利用现有 Vue 编辑器提供真实可运行的 VitePress 示例，帮助 API 文档作者展示可折叠、可搜索的 JSON。首版不新增独立插件包。

## 场景与范围

用户在 Markdown 中展示接口响应，读者可展开字段、复制数据，必要时主动进入编辑模式。交付建议位于 examples/vitepress，若组件在独立仓库则优先在那里维护。不要为多一个链接复制整个仓库。

不做 Markdown 自动全量转换、不自动替换所有代码块、不接入远程 JSON、不构建文档主题。

## 需求

### 集成与公共 API

检查组件发布入口、CSS、Vue 版本、SSR 行为及现有 API。先实现最小导入示例；仅在需要时新增轻量文档适配组件。

默认只读、根节点有限展开；支持复制、搜索、主题、最大高度和显式编辑开关。复用现有 API，缺少能力时先列差距，不能假设已支持。初始数据应有唯一来源，编辑后的值不自动写回文档文件。

### SSR 与渐进展示

检查 window/document、编辑器和 Worker 是否在模块导入时被访问。通过懒加载或客户端边界解决；不能简单用客户端包装掩盖仍发生在顶层导入的错误。

SSR 或 JS 未加载时提供有界静态预览或说明；明确该预览内容会进入公开 HTML，不得放敏感数据。防止 hydration mismatch，加载失败保留可读降级。

### 内容安全与性能

数据按文本或结构化输入处理，禁止把 JSON 字符串作为 HTML 执行。准备包含 script 标签、尖括号和 URL 的测试数据。

组件不应因输入过大阻塞文档页。根据已有编辑器限制设置阈值和用户提示，数值经过测试后确定；不要求本次解决任意规模数据。页面多实例不应共享用户编辑状态。

### 主题与交互

浅色/深色主题跟随文档站；CSS 不污染标题、代码块和导航。折叠与复制支持键盘操作，复制失败给出反馈。移动端不撑破页面。

### 来源与隐私

示例 README 提供 Live Demo、组件文档和源码链接。展示数据默认保留在当前文档页面；不把原文通过参数交给官网。主站“在线试用”可为空白工作区入口，不默认传数据。

## 示例页面

- API 响应示例：静态说明、交互式查看器、复制操作。
- JSON 编辑示例：用户主动启用编辑，展示变化事件，不写远程日志。
- 错误与限制：无效输入、超限输入、加载失败。
- 多实例与深色主题示例。

- [ ] 解决 SSR、CSS、主题和资源路径。

## 验收

干净安装后开发、构建、静态预览成功；直接访问页面无运行时异常；只读、复制、搜索和编辑开关按能力清单工作；多个实例互不污染；无外部 JSON 上传；构建内容不包含私有测试数据；卸载组件不影响文档站其他页面。

## 成效与扩展门槛

记录真实接入反馈、公开使用案例和支持问题，不追踪读者 JSON。只有重复出现自动注册或配置需求时，才另立 VitePress 插件需求；不能以增加 npm 页面为启动理由。

## 通用实施约束

1. 本文为需求与验收依据，不代表仓库已经具备文中能力。实施前检查实际代码、构建脚本、许可证、组件 API 和发布配置；不得虚构检查结果。
2. 产品名称统一为 JsonToolBox；官网为 https://jsontoolbox.cc/；主仓库为 https://github.com/kbmjj123/jsontoolbox.cc。新增包名、镜像名和仓库名均为待确认建议，发布前检查可用性。
3. 优先复用现有编辑器与处理逻辑，不复制维护第二套核心，不引入与需求无关的账号、数据库、云端处理和许可证验证服务。
4. JSON 内容不得默认上传、写入分析事件或附加在外部链接中；错误日志不得包含用户原文。不要把“本地处理”直接等同于整个页面没有外部请求。
5. 官网、源码和许可链接用于说明来源。不得要求强制反链、指定 dofollow、隐藏链接或堆砌关键词；品牌展示可关闭，不得影响功能。许可证义务以仓库实际许可证为准，不将保留网页反链描述为 MIT 的要求。
6. 新增追踪、外部服务、软件包发布、平台提交和对第三方发起 PR 均需维护者确认。默认不增加遥测。
7. 不为链接数量创建空壳包、重复仓库或无实际用途的适配层。下载、拉取、引用和真实用户分别统计，不混为一谈。
8. 使用项目现有包管理器、测试方案和编码规范；本文示例命名可按仓库结构调整，调整需说明理由。

## 开工前必须输出

- 相关文件、组件入口、构建命令及当前行为的检查记录。
- 已有能力、缺失能力和阻塞项列表；不能确认的内容标记“待核实”。
- 最小变更方案、拟修改文件清单及复用关系。
- 本次验收方式与回归范围。遇到架构或发布权限阻塞时停止猜测，记录需要维护者确认的决策。

## 交付与完成定义

- 可运行代码或配置、中文及英文使用说明、实际执行的测试结果、已知限制、回滚方式。
- 文档内命令必须在目标环境验证；未执行的测试标为“未验证”，不能直接勾选通过。
- 不影响官网现有工具、现有组件消费者及 Obsidian 插件；相关共享核心发生变更时执行回归。
- 发布前提供变更摘要、涉及外部服务清单和维护成本说明。未获得发布授权时仅交付待发布产物与操作说明。
