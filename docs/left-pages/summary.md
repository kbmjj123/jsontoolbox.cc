## 最终结论

你之前发来的页面已经覆盖了 JsonToolBox 的主干：

```text
编辑
格式化
压缩
验证
Diff
JSONPath
Schema
代码生成
JSON/YAML/XML/CSV/Excel/PDF 转换
Escape/Unescape
```

但根据最初 Semrush 报告，仍有以下明显遗漏：

1. **TXT to JSON**：报告中有 720 搜索量、KD 12 的低竞争机会。
2. **JSON to Text**：适合做简单、高可用的文本提取工具。
3. **JSON Parse/Stringify**：报告中有 KD 15 的 `json string to json object` 机会。
4. **JSONC/JSON Comments**：报告中有大量 comments 和 jsonc 词。
5. **HTML to JSON**：搜索量较低，但 KD 15 左右且实现成本低。
6. **JSON to TOON**：新兴 AI/LLM 数据格式，搜索量 880，但竞争和趋势风险都更高。
7. **JSON Array Generator**：适合补充示例、测试数据和 Schema/TypeScript 工具链。
8. **JSON 创建和 JSON 错误教程**：`create json file` 与 `unexpected end of json input` 的 KD 很友好。
9. **JSON vs JSONL/YAML/XML/TOON 对比内容**：适合建立主题权威和内链结构。

如果只增加 5 个，我建议：

```text
/tools/txt-to-json
/tools/json-to-text
/tools/json-parse
/tools/jsonc-to-json
/tools/html-to-json
```

如果考虑未来增长和产品差异化，再增加：

```text
/tools/json-to-toon
/tools/json-array-generator
```

最重要的不是把所有 3,900 个关键词都做成页面，而是将它们收敛成少量高质量的搜索意图页面。这样既能避免关键词蚕食，也能让 JsonToolBox 的工具之间形成更清晰的使用路径：

```text
Open/Edit JSON
→ Parse/Validate
→ Format/Minify
→ Query/Diff
→ Convert
→ Generate Schema/Code
→ Export to Text, CSV, PDF, YAML, XML, TOON
```
